## SECTION 1: TRUE / FALSE QUESTIONS (20 QUESTIONS)

**Instructions:** Select **True (T)** or **False (F)** for each statement based on the study guide modules. Detailed explanations are provided for verification.

1. **Artificial Intelligence has a single, universally agreed technical definition that is applied identically across every scientific discipline.**
   * **Answer:** **FALSE**
   * *Explanation:* As stated in Topic 1.1, there is no single definition used in every context. AI broadly refers to computational systems performing tasks associated with human cognitive abilities.

2. **A thermostat that turns on the heating when the ambient temperature drops below a set threshold is an example of rule-based automation, not data-driven AI.**
   * **Answer:** **TRUE**
   * *Explanation:* Rule-based automation follows fixed IF-THEN conditions defined by humans and does not learn patterns from data (Topic 1.3).

3. **In his 1950 paper, Alan Turing proposed an "imitation game" to evaluate whether a machine's conversational responses could be mistaken for a human's.**
   * **Answer:** **TRUE**
   * *Explanation:* Turing introduced this test to move past abstract philosophical debates about whether machines can "think" (Topic 2.2).

4. **Passing the Turing Test serves as definitive scientific proof that a computational system possesses human-like consciousness.**
   * **Answer:** **FALSE**
   * *Explanation:* Passing a conversational fluency test demonstrates performance under specified conditions, not inner feelings, intentions, or consciousness (Topic 2.2).

5. **An "AI Winter" refers to a historical period marked by declines in research funding and enthusiasm after expectations exceeded technical capabilities.**
   * **Answer:** **TRUE**
   * *Explanation:* AI winters occurred when ambitious claims outpaced what available algorithms, data, and hardware could deliver (Topic 2.5).

6. **Capability labels such as Narrow AI and AGI describe the specific technical architecture or algorithm used to construct a model.**
   * **Answer:** **FALSE**
   * *Explanation:* Capability labels describe the breadth of tasks a system can perform, whereas technique labels describe how it is built. These classifications answer different questions (Topic 3.1).

7. **Most deployed AI systems operating in the real world today are classified as Narrow AI (task-specific AI).**
   * **Answer:** **TRUE**
   * *Explanation:* Deployed tools (speech recognition, translation, recommendation systems) are bounded to specific tasks and lack general human-like abilities across unrelated domains (Topic 3.2).

8. **In Machine Learning terminology, a "feature" is the target answer or ground-truth label attached to a data sample.**
   * **Answer:** **FALSE**
   * *Explanation:* An input characteristic (e.g., message length, link count) is a feature; the target answer (e.g., "spam" or "not spam") is the label (Topic 4.2).

9. **Supervised Learning models learn mathematical relationships between input features and desired target labels.**
   * **Answer:** **TRUE**
   * *Explanation:* Supervised Learning requires labeled training examples so the algorithm can learn feature-to-label mapping (Topic 4.4).

10. **Overfitting occurs when a model performs exceptionally well on unseen test data but fails on its original training dataset.**
    * **Answer:** **FALSE**
    * *Explanation:* Overfitting is the exact opposite: the model performs well on training data but poorly on unseen test data because it memorized training noise (Topic 4.7).

11. **Deep Learning is a specialized branch of Machine Learning that uses artificial neural networks with multiple processing layers.**
    * **Answer:** **TRUE**
    * *Explanation:* The word "deep" refers specifically to the presence of multiple hidden computational layers in the network (Topic 5.1).

12. **Artificial neural networks are exact anatomical and biological replicas of the biological human brain.**
    * **Answer:** **FALSE**
    * *Explanation:* Neural networks are loosely inspired by biological nervous systems, but they are mathematical models and not literal copies of human brains (Topic 5.2).

13. **During training, backpropagation calculates error gradients backward through the network to help adjust internal weights and biases.**
    * **Answer:** **TRUE**
    * *Explanation:* Backpropagation evaluates how parameters contributed to the loss function error and updates them using optimization methods like gradient descent (Topic 5.4).

14. **All Generative AI systems are Large Language Models (LLMs).**
    * **Answer:** **FALSE**
    * *Explanation:* Generative AI includes text, image, audio, video, and code models. LLMs specifically focus on processing and generating language (Topic 6.1 & 6.5).

15. **Large Language Models generate text step-by-step by predicting the most statistically probable next token given the prompt and context.**
    * **Answer:** **TRUE**
    * *Explanation:* LLMs are autoregressive models that process token sequences and calculate probability distributions for the next token (Topic 6.2 & 6.3).

16. **An AI "hallucination" occurs when an LLM produces fluent, coherent text that contains factually false or fabricated information.**
    * **Answer:** **TRUE**
    * *Explanation:* Hallucinations occur because next-token prediction prioritizes language plausibility over verifying facts against reliable sources (Topic 6.4 & 6.7).

17. **An AI model deployed in a real-world setting constitutes a complete sociotechnical system on its own.**
    * **Answer:** **FALSE**
    * *Explanation:* A model is only one technical component. A sociotechnical system includes people, user interfaces, organizational policies, infrastructure, and decision workflows (Topic 7.8).

18. **Algorithmic bias can enter an AI system through unrepresentative training data or historical societal inequalities.**
    * **Answer:** **TRUE**
    * *Explanation:* Bias enters through unrepresentative datasets, flawed labeling, or historical inequalities embedded in training samples (Topic 8.3).

19. **Placing a human in a decision workflow automatically guarantees meaningful oversight, regardless of whether the person has time, expertise, or authority.**
    * **Answer:** **FALSE**
    * *Explanation:* Oversight is only meaningful when the human reviewer has sufficient information, time, expertise, and authority to question or override the system (Topic 8.7).

20. **When evaluating predictions about future AI developments, observed technical trends should be treated as identical to speculative scenarios.**
    * **Answer:** **FALSE**
    * *Explanation:* Responsible evaluation requires separating demonstrated capabilities and measured trends from speculative forecasts and hypothetical scenarios (Topic 9.7).

**Calculation Scenario:**  
A spam classifier is trained on 100 emails. During testing on 20 **new** unseen emails:
* Total actual spam emails in test set: 10
* Emails correctly predicted as spam (True Positives): 8
* Legitimate emails incorrectly flagged as spam (False Positives): 2
* Spam emails missed by the model (False Negatives): 2
* Legitimate emails correctly identified as legitimate (True Negatives): 8

Calculate the model's **Accuracy**, **Precision**, and **Recall** on the test set.

```
       WORKFLOW LIFECYCLE:
       [Problem Definition] ──► [Data Collection] ──► [Data Cleaning] 
                │
                ▼
       [Split Train/Test Data] ──► [Model Training] ──► [Evaluation] ──► [Deployment & Monitoring]
```

* **Sample Answer / Marking Guide (Word Count: ~250 words):**  
  * **7-Step ML Workflow:** (1) Define problem/desired output, (2) Collect relevant data, (3) Clean and prepare data, (4) Separate data into training and evaluation sets, (5) Train model parameters, (6) Evaluate performance on unseen data, (7) Deploy, monitor, and update model.  

  * **Core Definitions & Overfitting Analysis:**  
    * *Features* are measurable input variables (e.g., email word count, link count).  
    * *Labels* are target output categories (e.g., "Spam").

    * **Accuracy:** $\frac{\text{True Positives} + \text{True Negatives}}{\text{Total Test Samples}} = \frac{8 + 8}{20} = \frac{16}{20} = 80\%$  
    * **Precision:** $\frac{\text{True Positives}}{\text{True Positives} + \text{False Positives}} = \frac{8}{8 + 2} = \frac{8}{10} = 80\%$  
    * **Recall:** $\frac{\text{True Positives}}{\text{True Positives} + \text{False Negatives}} = \frac{8}{8 + 2} = \frac{8}{10} = 80\%$

### Question 3: Deep Neural Networks and Dataset Bias Scenarios

**Context & Activity Connection:**  
In Topic 5's learning activity (*Cat-vs-Dog Neural Network diagram and dataset bias experiment*), learners trace layer representations and analyze what happens when training data is skewed (e.g., dogs mostly outdoors on grass, cats mostly indoors on carpet).

**Prompt:**  
1. Draw or diagram the structural flow of an Artificial Neural Network, describing the specific roles of the **input layer**, **hidden layers**, **output layer**, **weights**, **biases**, and **activation functions**.  
2. Explain the step-by-step mathematical learning process (Forward Pass $\rightarrow$ Loss Function $\rightarrow$ Backpropagation).  
3. Analyze the failure case from the activity: If a deep neural network image classifier is trained on thousands of photos where dogs are always outdoors on grass and cats are always indoors on carpet, explain how feature extraction in hidden layers can lead to dataset bias, and predict how the model will perform when given a photo of a cat sitting on outdoor grass.

```
   INPUT LAYER             HIDDEN LAYERS             OUTPUT LAYER
(Raw Pixels: RGB)     (Hierarchical Features)      (Class Scores)
     [ x1 ] ─────────► [ h1 ] ─────────► [ h3 ] ─────────► [ Cat Prob: 15% ]
     [ x2 ] ─────────► [ h2 ] ─────────► [ h4 ] ─────────► [ Dog Prob: 85% ]
                           ▲
             (Weighted Connections w & Biases b)
```

* **Sample Answer / Marking Guide (Word Count: ~240 words):**  
  * **ANN Architecture & Functions:**  
    * *Input Layer:* Receives numerical features (e.g., RGB pixel brightness values).  
    * *Hidden Layers:* Perform mathematical transformations through weighted connections ($w$) and biases ($b$). Early layers detect low-level features (edges, textures), while deeper layers combine them into high-level features (shapes, visual objects).  
    * *Activation Functions:* Introduce non-linearity (e.g., ReLU), allowing the network to represent complex data relationships.  
    * *Output Layer:* Produces final predictions (e.g., class probability scores).  

  * **Learning Process:** During the *Forward Pass*, inputs propagate through layers to yield a prediction. The *Loss Function* quantifies the mathematical error between prediction and ground-truth label. *Backpropagation* calculates error gradients backward through the network, allowing optimization algorithms (Gradient Descent) to adjust weights and biases to reduce loss.  

  * **Dataset Bias Analysis:** Deep neural networks extract features based on statistical correlations in data. If all training dogs are on grass and cats are on carpet, hidden layers may extract "green background texture" as a primary mathematical feature for "Dog." When presented with an outdoor cat on grass, the model will likely misclassify the cat as a "Dog." This demonstrates that high training performance on skewed data does not guarantee safe generalization in real-world settings.

### Question 6: AI Ethics Review Checklist and Meaningful Human Oversight

**Context & Activity Connection:**  
Topic 8 introduces the 7-Pillar Ethical Review Checklist (Purpose, People, Data, Performance, Transparency, Human Control, Accountability) and Topic 8.7 explores human oversight. The activity involves performing an ethical audit on real-world AI deployment scenarios.

**Prompt:**  
1. Explain how **algorithmic bias** can enter an AI system even when developers have no malicious intent.  
2. Outline the **7-Pillar Ethical Review Checklist** from Topic 8.8.  
3. Drawing upon Topic 8.7, analyze why simply placing a human in a decision workflow ("Human-in-the-Loop") fails to provide **meaningful human oversight** if the reviewer lacks time, information, or authority. Provide a school or workplace example.

```
+-----------------------------------------------------------------------------------+
|                        7-PILLAR ETHICAL REVIEW CHECKLIST                          |
+------------+------------+------------+---------------+--------------+--------------+---------------+
| 1. Purpose | 2. People  | 3. Data    | 4. Performance| 5.Transparency|6.HumanControl|7.Accountability|
+------------+------------+------------+---------------+--------------+--------------+---------------+
```

* **Sample Answer / Marking Guide (Word Count: ~245 words):**  
  * **Algorithmic Bias:** Bias enters AI systems when training datasets reflect historical societal inequalities, unrepresentative demographic sampling, flawed ground-truth labels, or selective data collection. The model mathematically codifies and scales these historical patterns, producing systematically unfair outcomes under a false appearance of mathematical objectivity.  

  * **7-Pillar Ethical Checklist:**  
    1. *Purpose:* Legitimate, clearly defined goal.  
    2. *People:* Identification of affected stakeholders, potential harms, and excluded groups.  
    3. *Data:* Relevant, secure, lawful, and representative collection.  
    4. *Performance:* Tested for accuracy and error rates across different sub-groups in deployment contexts.  
    5. *Transparency:* Clear communication to users that AI is being used, including its limitations.  
    6. *Human Control:* Qualified personnel possess real ability to review and override outcomes.  
    7. *Accountability:* Explicit legal and organizational responsibility for errors and harms.  

  * **Meaningful Human Oversight Analysis:** Placing a human reviewer in a workflow is merely *symbolic oversight* if the reviewer is forced to process hundreds of automated decisions per hour without access to underlying data features or authority to challenge model outputs. For example, if a school uses an AI tool to flag "at-risk failing students" and a teacher is required to approve 300 automated flags per day without time to check individual student circumstances, the teacher becomes a rubber stamp. Meaningful oversight requires adequate time, complete diagnostic information, expertise, and operational authority to override the system.
