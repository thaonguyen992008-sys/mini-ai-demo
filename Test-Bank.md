### Section 3: Open-ended Answer Key

#### Question 1: AI vs. Automation
1. **Explanation:** Rule-based automation follows fixed human-written instructions (IF-THEN) without learning. Data-driven AI learns patterns from data to make predictions or decisions in dynamic situations.
2. **Classifications:**
   
    **Item A:** Rule-Based Automation (fixed time rule).

    **Item B:** Data-Driven AI (learns user viewing patterns).

    **Item C:** Rule-Based Automation (fixed mathematical calculation).

#### Question 2: Supervised vs. Unsupervised Learning
1. **Definitions:**
   
    \+ *Supervised Learning:* The model trains on labeled data (inputs paired with correct answers).

    \+ *Unsupervised Learning:* The model looks for hidden structures/clusters in unlabeled data without target answers.
3. **Examples:**
   
    \+ *Supervised Example:* A email spam filter trained on messages marked "Spam" or "Not Spam".
   
    \+ *Unsupervised Example:* Customer segmentation where a store groups shoppers by purchasing habits without pre-assigned labels.

#### Question 3: Writing a Good Prompt
1. **4 Components:** Task, Context, Audience, Format (or Constraints).
2. **Sample Prompt:**  
   > "Act as a elementary school teacher (Context). Explain what Machine Learning is (Task) to an 8-year-old child (Audience). Use a simple story about a dog learning tricks and format it as 3 short bullet points (Format/Constraints)."

#### Question 4: ML Metrics & Testing Data
1. **Why Test on Unseen Data:** Testing on new data reveals whether the model truly learned general patterns or simply memorized the training data (overfitting).
2. **Precision Calculation:**  
   $$\text{Precision} = \frac{\text{True Positives}}{\text{Total Predicted Positives}} = \frac{4}{5} = 0.80 = 80\%$$

#### Question 5: Deep Learning & Neural Network Layers
1. **3 Main Layer Types:** Input Layer $\rightarrow$ Hidden Layers $\rightarrow$ Output Layer.
2. **Feature Extraction:**
   
    \+ *Early Hidden Layers:* Detect simple visual elements like edges, lines, and color contrast.

    \+ *Deep Hidden Layers:* Combine simple patterns into complex shapes (cat ears, eyes, whiskers) to determine the class.

#### Question 6: Ethical Risk & Meaningful Human Oversight
1. **Algorithmic Bias:** If historical data contains past human prejudices or lacks examples from certain demographic groups, the model learns and repeats those unfair patterns in its predictions.
2. **Meaningful Human Oversight:** Oversight is only meaningful if the human reviewer has the time, knowledge, diagnostic info, and real power to reject or change an AI's decision. If a reviewer simply clicks "Approve" without reading (rubber-stamping), errors and biased decisions pass through uncorrected, creating an unsafe system.
