# AI Technologies

## 1. Introduction

AI technologies enable computers to learn from data,
recognize patterns, process information, and generate content.

## 2. Machine Learning (ML)

Machine Learning is a branch of AI that enables computers
to learn patterns from data and make predictions.

Examples:
- Product recommendations
- Spam email detection
- Weather prediction

## 3. Deep Learning (DL)

Deep Learning is a type of Machine Learning that uses
multi-layered neural networks to learn complex patterns.

Examples:
- Image recognition
- Speech recognition
- Language processing

## 4. Natural Language Processing (NLP)

NLP enables computers to process, analyze, and generate
human language.

Examples:
- Language translation
- Chatbots
- Text analysis

## 5. Generative AI

Generative AI creates new content based on patterns
learned from training data.

It can generate:
- Text
- Images
- Audio
- Videos
- Computer code

## 6. How Are These Technologies Related?

AI is the broader field.

Machine Learning is a branch of AI, and Deep Learning
is a type of Machine Learning.

NLP focuses on human language, while Generative AI
focuses on creating new content. These technologies
can overlap in the same AI system.
